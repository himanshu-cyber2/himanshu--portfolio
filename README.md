## 🛠️ Built With

- **Expense Hub:** A financial logging interface for monitoring transaction flows.
- **Dynamic 3D Background:** A crystalline WebGL environment that reacts to user scroll and mouse movement.

## 📁 Project Structure
- `index.html`: Core structure and SEO.
- `style.css`: Custom glassmorphism and layout styling.
- `script.js`: Three.js engine, GSAP triggers, and interactive app logic.
